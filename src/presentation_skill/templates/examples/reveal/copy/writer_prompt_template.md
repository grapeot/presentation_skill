# Task: write the on-screen copy and the speaker notes for a lecture deck

Read these files completely before writing (absolute paths):
- deck_brief.md (slides by id, copy slots, word limits, minutes)
- source_contract.md (the only facts you may use)
- voice_contract.md (how it should sound)

Write ONE file, copy.md, with this structure for every slide in the brief, in order:

```
## slide_id
slot_name: text

### notes
Spoken script paragraphs.
```

Rules:
- Fill every slot with the brief's slot names; copy FIXED slots exactly; respect every word limit.
- Notes ≈ minutes × 130 words per slide.
- Use only facts from the source contract. Add no statistics, names, anecdotes, dates or quotes. Keep qualifiers.
- Tie every abstract claim to a concrete example from the contract.
- End each slide's notes by setting up the next slide's first sentence.
- Write nothing else and create no other files.
