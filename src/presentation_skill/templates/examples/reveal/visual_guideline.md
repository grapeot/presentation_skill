# Visual guideline (reference: printed atlas)

Replace this file with the deck's own guideline before generating any plate.

- **Register:** one publication on one sheet. Warm paper, near-black ink, textless engraving plates, running header and footer.
- **Paper and ink:** paper `#f2ede2` with a fixed grain layer (it never moves with the camera); ink `#1b2130`; secondary `#4a5162`; tertiary `#8b8f99`; rules `#cfc6b3`; cards `#f7f3ea`.
- **Semantic accents:** at most two, one meaning each. Here, blue `#23407a` means lasting or appreciating, and vermilion `#b6422a` means expiring or at risk. Structural rules stay ink.
- **Type:** a display serif with optical sizing (Fraunces) for claims; a sans (Inter) for labels and kickers; a mono (JetBrains Mono) for numbers and sources. Body 26–40 px at 1080p; nothing below 20 px except source lines (17 px).
- **Plates:** one style paragraph for the whole set; one subject per plate; no text or numbers; converted to ink on transparent; never behind text that is being read.
- **Italics:** reserved for one recurring device (for example two recurring questions), so each use lands.
- **Forbidden:** decorative gradients, icon grids, stock tech imagery, a third accent colour, dark UI widgets pasted into a paper deck, claims set as small grey eyebrows.
